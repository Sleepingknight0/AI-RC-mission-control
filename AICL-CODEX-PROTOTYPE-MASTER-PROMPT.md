## Non-negotiable invariants

Preserve all of the following:

- Frontend sees normalized AICL protocol messages only, never raw provider events.
- Session, Runtime, Turn, Connection, Command, Approval, and Event remain distinct concepts.
- Core and Connector remain separate processes.
- Connector never mutates the Core database.
- One executing Turn per Session; no `queued` Turn state in Prototype 0.
- Connector/provider process loss cannot be reattached over old stdio. Mark the old runtime lost and unresolved active work `outcome_unknown` when terminal outcome cannot be proven.
- Never auto-resubmit a potentially side-effecting prompt.
- Every client mutation uses a stable `commandId`; duplicate IDs return the prior result and do not redispatch.
- Durable events commit before broadcast. Ephemeral deltas may stream immediately and are coalesced; do not insert one database row per token.
- Resource revisions are independent of event sequence numbers.
- Approval resolution uses compare-and-set on the approval resource and runtime generation, not a global session revision.
- No unrestricted remote shell endpoint.
- Apply canonical project-root allowlist checks before filesystem or provider access.
- WebSocket envelopes remain within the configured limit; large diffs use artifacts.

## Quality bar

- TypeScript strict mode; no unexplained `any` at protocol/process boundaries.
- Stable machine-readable error codes.
- Explicit timeout, cancellation, retry-safety, and process-termination behavior.
- No swallowed exceptions or secret-bearing logs.
- Generated provider schemas are isolated behind the Codex adapter.
- Tests should exercise behavior, not merely snapshot implementation details.
- Windows paths and process-tree termination must be considered explicitly.
