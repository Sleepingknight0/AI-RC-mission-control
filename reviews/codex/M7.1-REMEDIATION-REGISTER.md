## Policy Clarifications

- Channel loss alone is not immediate process death. A same-identity reconnect
  within the ownership lease preserves work; lease expiry is the explicit point
  where unverified ownership becomes `outcome_unknown`.
- Prototype 0 browser authentication is a per-launch local capability, not the
  full passkey/device system from the long-form target design.
- Windows `shell: true` remains allowed only for the resolved, operator-owned
  Codex command and fixed arguments. No remote field may enter that command line.
- Completed assistant content above the normalized envelope ceiling fails closed
  as uncertain provider output; automatic prompt replay remains forbidden.

Every accepted row ends M7.1 with a regression test and a concrete evidence
entry below. M7.2 remains a separate clean-checkout and real-provider gate.
